# Inbox (`.raw/`)

Drop raw sources here — PDFs, article text, transcripts, exported clips —
anything you want turned into linked wiki pages.

## How to use

1. Add a file (or paste text into a chat).
2. Run `/ingest` (or say "ingest all of these").
3. The agent reads each source, extracts people and concepts, cross-links them,
   and files a page under [`../sources/`](../sources/). This inbox is then clear.

Files left here are considered **unprocessed**. Keep it empty between sessions.
