# Welcome — Start Here

You are looking at a plain-Markdown knowledge vault. Everything is a file you
own. The AI operating protocol lives in [`../WIKI.md`](../WIKI.md).

## The loop

1. **Feed it a source** — drop into [`../.raw/`](../.raw/) and run `/ingest`.
2. **Ask it anything** — "what do you know about X?"; answers cite their pages.
3. **Save a conversation** — run `/save` to make a permanent note.
4. **Keep it clean** — run `/lint` weekly.

## Where things go

- Ideas → [`../concepts/`](../concepts/)
- People/orgs → [`../people/`](../people/)
- Sources → [`../sources/`](../sources/)
- Everything else → [`../notes/`](../notes/)
